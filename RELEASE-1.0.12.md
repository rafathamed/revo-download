# REVO Download 1.0.13

This release strengthens browser video discovery across direct media URLs, extensionless media responses, HLS/DASH manifests, page-world fetch/XHR, and dynamically assigned video sources. It avoids treating ordinary MSE segment requests as standalone files.

Release source version: `1.0.13`.

This release includes the torrent cleanup completion fix and the Windows release workflow adjustment that makes Firefox add-on signing optional while keeping the signed update metadata requirement for official releases.

The Windows installer and signed update manifest are produced by the GitHub Actions release workflow.
